# Consent Guard 발표 리허설

발표 직전 점검과, 웹 앱 장면 1~5를 실제로 돌려 본 소요 시간. 테스트넷에는 아무것도 쓰지 않는다. 상세 조작·오프라인 대체는 `docs/RUNBOOK.md`를 본다.

## 발표 직전 점검

- Node **23.6 이상** (루트 `.nvmrc`). 저장소 루트에서 **`npm ci`** 가 끝나 있어야 한다.
- 시스템 Chrome/Chromium. 기본 후보는 `/usr/bin/google-chrome`. 없으면 `CHROME_PATH`에 실행 파일 경로를 넣는다. 스크립트는 `apps/web/scripts/chromePath.mjs`의 `resolveChromePath()`로 같은 경로를 찾는다.
- 빠른 확인(선택): `npm test`, `npm run typecheck`, `npm run e2e`, `npm run demo:cli`.
- 미리보기 빌드: `npm run build && npm run preview -- --host 127.0.0.1 --port 4173 --strictPort`. 브라우저는 `http://127.0.0.1:4173/` (라이브) 또는 `http://127.0.0.1:4173/?mock=1` (오프라인).
- **포트.** preview는 4173. `verify:serve`도 4173이라 동시에 띄우지 않는다. e2e·`demo:video`는 4174, `demo:screens`는 4175.
- 라이브 앵커는 공개 RPC `read_anchor`만 읽는다. 키 없음. `CONSENT_GUARD_ALLOW_TESTNET_WRITE`는 켜지 않는다.
- 인터넷이 불안하면 `/?mock=1`로 전환하거나, `docs/RUNBOOK.md`의 백업 영상·`demo/screens/`를 쓴다.
- 창 크기는 1280×800에 가깝게. 장면 5 뒤에 감사 로그 `해시 체인 검증 ✓`, 앵커 패널 `현재 장부 = 온체인 앵커 일치 ✓`가 보여야 한다.

## 다섯 장면

1. 처음 화면 — 카드 내역 허용, 가맹점명 `***`, AI 배지 `recorded`. 앵커 패널은 `11건 중 N건 · 앵커 전`.
2. 계좌번호 원문 요청은 이미 `거부`.
3. 진료기록 대기 요청을 **허용**.
4. **+10분** — 알레르기 권한 만료, 후속 요청 거부.
5. 카드 권한 **철회** — 재요청 거부. 이어서 체인·앵커 일치 확인.

## 측정 방법

날짜: 2026-11-20 (Asia/Seoul).

- 대상: 미리보기 빌드 `http://127.0.0.1:4173/` (라이브 RPC)와 `http://127.0.0.1:4173/?mock=1`.
- 브라우저: 시스템 Chrome, `resolveChromePath()`.
- 각 장면은 화면이 안정된 뒤 **약 2.5초** 읽는 시간을 넣었다 (발표 호흡을 흉내). 장면 1에는 첫 로드와 앵커 패널 대기 시간이 포함된다.
- 라이브와 목 각각 **3회**. 아래는 그 측정값이다.
- 원시 기록은 저장소 안 `evidence/rehearsal/` (`timing-real.json`, `timing-mock.json`). `evidence/`는 gitignore라 커밋하지 않는다.

이 숫자는 **클릭과 읽는 시간**이다. 말로 설명하는 시간은 빠져 있다. 그래도 5분(300초) 한도 안에는 여유가 크다.

## 다시 돌리려면

미리보기를 `127.0.0.1:4173`에 띄운 뒤, 시스템 Chrome으로 위 다섯 장면을 라이브와 `/?mock=1` 각각 세 번 진행하고 장면·합계 시간을 적는다. 창 크기와 읽는 호흡을 맞추면 이 표와 비교할 수 있다.
