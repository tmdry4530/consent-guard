Consent Guard프라이버시 보장

프라이버시 보장

  1. 1
    원문 금지 필드 차단 account_number, card_number, resident_id, ssn, cvv, password는 어떤 동의가 있어도 거부.
  2. 2
    마스킹 동의의 maskFields는 값이 *** 로 바뀌어 전달되고, 동의 범위 밖 필드는 아예 전달되지 않음(요청에 포함되면 거부).
  3. 3
    철회 즉시 차단 revokedAt 이후 요청은 거부되며, 재요청 시 AI 호출 0회.
  4. 4
    해시 체인 각 이벤트(grant / access / deny / pending / revoke)를 canonical JSON의 sha256으로 연결. 변조 시 실패 위치와 사유까지 검출하고, 꼬리 절단은 앵커 비교로 검출.
  5. 5
    온체인 앵커 NEAR 테스트넷 계정 consent-guard-anchor.tee-receipts-chamdom.testnet에 장부 헤드 해시와 개수를 기록.
    현재 앵커(웹 데모 최종 장부): 11건, 헤드 259dbd26…fa95b, 블록 278,539,285,
    tx 51udtFvQ4Po2E4Pj6H2gTTKAvK2VRKCGgBeAN7A25P2y.

한계 현재

  • AI 답변은 녹화된 응답(recorded)이다. 실제 LLM을 호출하지 않으며 API 키도 없다.
  • 앵커는 NEAR 테스트넷 전용이다. 앵커 스크립트는 기본 dry-run이다.
  • 카드 내역·진료기록 등 데모 데이터는 모두 합성(가상)이다.
  • 앵커는 웹 데모 5장면의 최종 장부 하나뿐이다.

다음 단계 계획

  • 메인넷 앵커
  • 정책·마스킹을 유지한 채 라이브 모델 연동
  • 여러 시나리오·장부를 앵커할 수 있게 확장

다음 단계는 계획이며, 현재 구현된 기능이 아니다.
